DSH TurboWarp Bridge

把 TurboWarp 编辑器接到 DeepSeek Harness，让 AI 读改你的积木。

高级：桥地址（一般不用改）

默认 ws://127.0.0.1:31820。只有当插件跑在别的端口时才需要改 （比如并行跑验收脚本、或者你同时开了两个 dsh profile）。

token 从哪来？
  1. 对 dsh 里的 AI 说一句「我的 TurboWarp 连不上」，它调 scratch_list_sessions 会把 token 念给你。
  2. 或者看 dsh 的启动日志：有一行 桥 token: xxxx。
  3. 也可以直接开这个文件看：%APPDATA%\dsh-desktop\harness\scratch-bridge-token.txt（CLI 版是 ~/.dsh/scratch-bridge-token.txt）。
为什么要 token？

桥是本地 WebSocket（ws://127.0.0.1:31820）。WebSocket 不受同源策略限制， 你访问的任意网页都能去连它。没有 token 的话，那个页面可以冒充编辑器、伪造工具返回值， 甚至把文字塞进 AI 的上下文里。填了 token 之后，只有拿着正确 token 的连接会被接受。

填完还是连不上？
  1. 确认 dsh 正在运行（插件已加载），否则没人监听 31820。
  2. 刷新一次 turbowarp.org 页面；F12 看 [dsh-bridge] 开头的日志。
  3. 日志里出现 认证失败 = token 不对，回上面重新复制一份。
