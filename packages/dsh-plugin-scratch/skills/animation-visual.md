# 动画与视觉：社区审美笔记

> 适用场景：做 UI、转场、粒子、角色动画时读。
> 基于真实作品观察：样本里**大多数用画笔（pen）**，造型切换是主力动画手段，滑动类效果很少见。
> 只记做法——想量某个作品的规模，自己调 `scratch_snapshot` 或 `lab/inspect-sb3.mjs`。

## 动画的三个来源（按社区使用量排序）

### 1. 造型帧动画（主力）

**帧率纪律**：`重复执行 { 下一个造型, 等待 (0.05~0.1) 秒 }` 是唯一正确姿势。没有 wait 会一帧跑完。

```
当接收到 [走路]
  重复直到 <不在移动>
    下一个造型
    等待 0.08 秒
```

社区作品的角色动画普遍 6-12 个造型/动作；逐帧手绘的角色会到几十个造型（一笔一笔画出来的）。

**自制像素字库**：用一堆造型存字符图（`A_1`、`B_1`…），按 `字符 x of 文本` 索引克隆摆字——在没法装字体的 Scratch 里显示自定义字体。做像素风 HUD 时可以抄这招。

### 2. 画笔绘制（样本里最主流的视觉手段）

社区用 pen 干的事：
- **血条/冷却条**：`落笔` 画矩形，宽度 = 血量比例。比造型缩放精确（拉长不变形）
- **弹幕轨迹**：克隆体移动时 pen_stamp 留残影
- **过场动画**：canvas 扩展（TurboWarp 专属）的 `canvas_save/restore/stampOnStage` 画歌词背景

**性能纪律**：pen 图层永不清除会越叠越卡。转场/每帧重绘场景必须 `全部擦除`（pen_clear）后重画；残影效果反而要靠「不清除」——想清楚你要哪个。

### 3. 运动+参数动画（辅助）

- 缓动：`(目标-当前)×0.1` 每帧加一点（见 code-patterns 第 1 招）
- `在 1 秒内滑行到 x,y`（glide）：样本里极少见——社区不爱用（不可中断、和其它块时序冲突）。手动 forever+每帧 move 更可控
- 尺寸/透明度当动效：`将大小增加 -2` 做消散、`将 [幽灵] 特效设为 50` 做淡入

## 转场黑幕（社区标配）

惯用命名是一对广播：`Blackout Start` / `Blackout End`：

```
当接收到 [Blackout Start]
  移到最前面
  显示
  重复 (10) 次 { 将 [幽灵] 特效增加 -10, 等待 0.02 秒 }  // 0.2s 淡入全黑
  广播并等待 [切换场景]
  重复 (10) 次 { 将 [幽灵] 特效增加 10, 等待 0.02 秒 }   // 淡出
  隐藏
```

一个专用「ABANDON」/「过渡」精灵全责。**转场是独立模块**，不塞在业务脚本里。

## UI 审美：社区高级作品的共同点

1. **按钮 = 造型对**（normal/hover/pressed 三造型），切换响应 < 0.1s，配合 `角色被点击` hat。**一个按钮精灵管全部 UI**（每个按钮一个造型，几十个造型也正常）。
2. **数字显示用造型**（不是说）：`0` 到 `9` 各一造型，按位数克隆拼接——计分板不闪烁、像素风统一。
3. **血条不用角色**：pen 画 + 每帧重算宽度，配 `图层` 控制（`移到最前`）。
4. **HUD 分层**：`图层//前`（HUD）、`图层//中前`（角色）、`图层//后`（背景）——**专门开图层管理精灵**，每层一个角色，入场时统一 `移到 x 层`。常见 4-5 层。

## 什么会让作品一眼「幼儿化」（agent 自查）

- 默认猫咪角色 + 默认「说 2 秒」气泡 → 换造型或至少改尺寸/特效
- 移动是瞬移（gotoxy 无过渡）→ 加缓动
- 没有入场/出场动画：东西直接出现/消失 → 至少加 `将 [幽灵] 特效` 淡入淡出
- 颜色全用默认蓝紫 → 用 2-3 个主色（社区爱用深底+高饱和强调色）
- 没有音效节点：静默交互 → 关键动作配 sound_play 或至少 volume 控制

## 什么会「不像 Scratch」（跑不起来的高级感）

- 想用 shader/滤镜（没有，只有 7 种 looks 特效：颜色、鱼眼、旋转、像素化、马赛克、亮度、幽灵）
- 想要 post-processing（pen + 图层是全部了）
- 想要 web 字体（只能造型字库，见上）
- 想要真并发锁（广播并等待是最接近的）

**结论：Scratch 的「高级感」= 缓动数学 + 图层管理 + pen 精确绘制 + 造型帧纪律**。这四样都做到了，观感立刻脱离入门档。
