# 实战教学样例：可以直接抄的完整脚本

> 适用场景：不确定「正确姿势长什么样」时，来这找最短正确版本。
> 全部按 sb3 blocks dict 写出（scratch_add_blocks 可直接用）。

## 样例 1：键盘移动（四面）+ 边界

```
当绿旗被点击
  显示
  永远
    如果 <按下 [上移 ↑] 键?> 那么 { 将 y 坐标增加 4 }
    如果 <按下 [下移 ↓] 键?> 那么 { 将 y 坐标增加 -4 }
    如果 <按下 [右移 →] 键?> 那么 { 将 x 坐标增加 4 }
    如果 <按下 [左移 ←] 键?> 那么 { 将 x 坐标增加 -4 }
    如果 <(y 坐标) > 170> 那么 { 将 y 设为 170 }    // 边界夹紧（170 留给造型半高）
    如果 <(y 坐标) < -170> 那么 { 将 y 设为 -170 }
    如果 <(x 坐标) > 230> 那么 { 将 x 设为 230 }
    如果 <(x 坐标) < -230> 那么 { 将 x 设为 -230 }
    等待 0.02 秒
```

要点：4 个独立 if（不是 if-else——斜着走要同时响应两键）、边界夹紧而非反弹（新手爱用「碰到边缘就反弹」但那会改变朝向）。

## 样例 2：克隆体弹幕（扇形发射）

```
--- 生成器角色（敌人） ---
当接收到 [发射弹幕]
  重复 (24) 次
    生成 [子弹] 的克隆体
    等待 0.05 秒

--- 子弹角色 ---
当作为克隆体启动时
  移到 x:(敌人x) y:(敌人y)
  面向 (随机取 160 到 200) 度     // 扇形角度域
  重复执行直到 <<(y 坐标) > 180> 或 <碰到 [玩家] ?>>
    移动 6 步
  删除此克隆体
```

要点：**克隆体进门就定死亡条件**（出屏或命中）；生成器节流（wait 0.05）防一帧爆量（TW 无 300 限但瞬时几千克隆会掉帧，且发回原版 sc 就真炸）。

## 样例 3：平滑镜头跟随（缓动）

```
当绿旗被点击
  永远
    将 [镜头x] 设为 ((镜头x) + (((玩家x) - (镜头x)) * 0.12))
    将 [镜头y] 设为 ((镜头y) + (((玩家y) - (镜头y)) * 0.12))
    广播 [镜头更新]      // 各图层精灵监听并按 (自己x - 镜头x + 240) 摆位
    等待 0.02 秒
```

要点：0.12 是社区验证过的跟手率（约 0.3s 收敛）；视差 = 每层用不同系数（远层 0.5、近层 1.2）。

## 样例 4：计时器驱动的帧动画

```
当绿旗被点击
  计时器归零
  永远
    将 [当前帧] 设为 (((计时器) * 10) 除以 (1) 的向下取整) mod (总帧数)
    换成 [第 ((当前帧)+(1)) 个] 造型
```

要点：timer 驱动 = 重开绿旗动画不同步的根治法；`mod` 循环帧。

## 样例 5：存档码（字符串序列化）

```
定义 存档
  将 [输出串] 设为 (连接 ((分数)) 和 (连接 ":" 和 ((关卡))))
  说 (输出串)     // 用户复制这个字符串

定义 读档 (码)
  将 [分数] 设为 (在 ":" 前的部分 of (码))
  将 [关卡] 设为 (在 ":" 后的部分 of (码))
```

要点：分隔符用不常见字符（社区用 ":" "|" "," 或 Unicode 符号）；数字列表用 `join` 全拼。**让一个专职精灵干这个**（社区常见做法是把序列化单独做成一个 LOADER 模块），别把解析逻辑散在业务里。

## 样例 6：按钮三态（用造型）

```
--- 按钮角色，三造型：normal / hover / pressed ---
当角色被点击
  换成 [pressed] 造型
  播放声音 [点击]
  广播并等待 [按钮:开始]
  等待 0.1 秒
  换成 [normal] 造型

当绿旗被点击
  永远
    如果 <碰到 [鼠标指针]?> 那么 { 换成 [hover] 造型 } 否则 { 换成 [normal] 造型 }
    等待 0.05 秒
```

要点：点击**立即**视觉反馈（0 帧延迟），业务逻辑广播出去（解耦）。

## 样例 7：pen 血条

```
当接收到 [更新血条]
  全部擦除
  抬笔
  移到 x:(-200) y:(150)
  面向 90 度
  将画笔大小设为 15
  将画笔颜色设为 (红色)
  落笔
  移动 ((血量) / (最大血量) * 400) 步     // 比例宽度
  抬笔
```

要点：每帧先擦再画；**移动比例**让条形任意长度可调；画笔大小即条高。

## 样例 8：状态机切换场景

```
--- Stage ---
当绿旗被点击
  将 [场景] 设为 [标题]
  永远
    如果 <(场景) = [标题]> 那么 { ...标题逻辑... }
    如果 <(场景) = [游戏中]> 那么 { ... }
    如果 <(场景) = [结束]> 那么 { ... }
    等待 0.02 秒
```

要点：变量 `场景` 是唯一事实源；切场景 = 改变量+广播 `_ 场景切换`（各精灵自行显隐）。**不要**用「谁显示着」反推状态。
