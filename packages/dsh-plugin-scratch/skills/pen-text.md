# 画笔文字引擎（背包里的「文字引擎」）

> 适用场景：要在作品里画**中文界面、标题、数字面板、字幕、打字机效果**，又不想用「说」气泡（中文会被截断、行高不可控、还带个框）。
> 直接取用：`scratch_backpack_load({ name: "文字引擎", target: "要画字的角色" })`。
> 本文写清楚它怎么用、内部编码长什么样（要改要加字就得懂）、以及四个必踩的坑。

---

## 1. 为什么不用造型堆字

造型堆字（一个字一个造型 / 一个字一个角色）在 20 个字以内没事，一过 50 个字就开始难受：造型列表变得很长、切换靠 `造型编号` 对表、居中要自己量宽度、改字号要重做造型。

这个引擎换了个存法：**字形不是一个造型，而是一串 16 进制文本**，画的时候用画笔沿笔画描出来。于是：

- 一个字 ≈ 40 个点 ≈ 130 个字符的文本；4 万多个字全部装在一个列表里（约 5 MB），**不占造型**。
- 字号随便给，因为是描线不是缩放位图。
- 颜色 = 笔的颜色，粗细 = 笔的大小，都能随时改。

## 2. 怎么用（三块积木）

```
当绿旗被点击
  笔迹全部擦除
  笔的颜色设为 [#111111]
  调用 画文本 ("你好，世界 Hello 123", -220, 120, 32)
```

`画文本 (内容, x, y, 字号)`：

| 参数 | 含义 |
|---|---|
| 内容 | 字符串。没有的字**不会画也不会报错**，光标照走 |
| x, y | 这段文字的**左上角**（y 往下长，正文基线不是它） |
| 字号 | 字高，单位像素。`字号 32` ≈ 一个字 32 像素高 |

画完的字是**画笔图层**上的像素：不在角色身上，不随角色移动，`清空笔迹` 之外没别的办法擦掉。

常用姿势：

```
每帧重画一行会抖 → 记一个「上次画的内容」，只有内容变了才重画。
居中：先用 宽 = 文字宽度(内容, 字号)（见 §5）算出宽度，再 调用 画文本(内容, -宽/2, y, 字号)
换行：自己按 宽度 累加，超了就把 x 归位、y 减 行高（引擎不管换行）
```

## 3. 它是怎么画出来的（内部结构）

4 个自定义块，全部开了「运行时不刷新屏幕」：

| 自定义块 | 干什么 |
|---|---|
| `画文本 %s %s %s %s` | 逐字循环：`找字` → 找到就 `画字` → `x = x + 字宽度` |
| `画字 %s %s %s %s` | 解一个字的笔画串，沿点描线（`笔的大小 = 字号/24`） |
| `定位 %s %s %s` | 解一个点：3 位 16 进制 → 坐标 → `移到 x y` |
| `找字 %s 大写: %s` | 在 `PTE-字库索引` 里二分查找这个字符 |

两张**全局**表（挂舞台，各角色共用一份，别删）：

| 列表 | 内容 |
|---|---|
| `PTE-字体` | 4 万多项，`第 n 项` 就是一个字的字形串 |
| `PTE-字库索引` | 4 万多项，把「字体」的下标按字符排好序，给二分查找用 |

`PTE-` 开头的几个标量（`PTE-x` `PTE-y` `PTE-找字i` `PTE-字代码` `PTE-字宽度` `PTE-定位x` `PTE-定位y`）是引擎的运行中间量，**别在别的脚本里用这几个名字**。加前缀就是为了这个。

## 4. 字形编码（要加字/换字体才需要看）

`PTE-字体` 的每一项 = `<字符><宽度><笔画…>`：

```
字体[2] =  !0b285845MA04A05
           │ │└────────────┘
           │ └ 2 位 16 进制：宽度 0x0b = 11（单位 1/64 字高）
           └ 字符本身 '!'
```

- **宽度**：两位 16 进制，单位是 1/64 字号。`字号 × 宽度 / 64` = 这个字占多宽。
- **笔画**：从第 4 位起，每 **3 位 16 进制 = 一个点**。12 bit 拆成：`低 6 位 = x`、`高 6 位 = y`，单位也是 1/64 字号，**y 向下**（坐标系是 64×64 的方格）。
- **`M` 是分隔符**：一段笔画里笔是连续的，遇到 `M` 就抬笔、跳到下一个点重新落笔。所以一个字可以有十几段笔画（比如「四」）。
- 一个 64×64 的方格刚好覆盖一个字：`0`～`63`。

对照着看：`!` 是 `[5,10] → [5,33]` 一段（那根竖线）+ `[4,40] → [5,40]` 一段（那个点）。

自己造字/加字：

1. 把一个字画成矢量，按 64×64 网格取点（转折点和端点就行，直线段中间不用记）；
2. 每个点编码成 `y × 64 + x`，再转 3 位 16 进制（不足补 0）；
3. 段与段之间插 `M`；
4. 前面拼上字符 + 两位 16 进制宽度，`add to list` 进 `PTE-字体`；
5. **`PTE-字库索引` 必须重新排序**，否则二分查找找不到它 —— 索引里存的是 `PTE-字体` 的下标，按字符升序（忽略大小写，和 Scratch 的 `<` 一致）。

## 5. 两个常用配方（自己搭，不占引擎）

**① 量一段文字多宽**（居中、右对齐、自动换行都要）：

```
设 宽 = 0
设 序号 = 0
重复 ( 内容 的字符数 ) {
  序号 + 1
  调用 找字 ( 内容 的第 序号 个字符, 0 )     ← 结果落在 PTE-找字i
  设 字 = ( PTE-字体 的 第 (PTE-找字i) 项 )
  设 宽 = 宽 + ( (字号) × ( 0x 连 ( ( 字 的第 2 个字符 ) 连 ( 字 的第 3 个字符 ) ) ) / 64 )
}
```

**② 判断这个字画不画得出来**（用户输入、生僻字）：

```
调用 找字 ( 字, 0 )
如果 ( ( PTE-字体 的 (PTE-找字i) 项 的第 1 个字符 ) = 字 ) { 有 } 否则 { 没有 }
```

## 6. 坑

1. **别在 `forever` 里每帧重画**。一次 `画文本` 就是几千个块（每个笔画点都是一次 `定位` 调用）。实测 370 个汉字（约 1.5 万个点）能在一帧内画完，所以偶尔画一下完全不疼；但每帧都画就是在给帧预算交税，而且画笔图层每帧重刷。**改内容才重画。**
2. **文字不在角色身上**。角色移动、克隆、`造型换成` 都不会带走它。要「跟着角色飘的字」就每帧擦掉重画（那就接受第 1 条），或者干脆用造型。
3. **同时画两段文字会串**。引擎用全局变量存中间量；`画文本` 开了 warp，单次调用是原子的，但**两个线程交替各调一次**时，后一个会把前一个的 `PTE-字代码` 覆盖掉。要么串行（一个线程画完再画下一个），要么给这类异步场景各自加锁（一个「正在画」的变量 + `等到`）。
4. **字库里没有的字静默跳过**。不报错、不画、光标按上一个字的宽度前进 —— 看起来就是「少了个字」。用 §5 ② 先判。
5. **缩得太小会糊/断**。笔的粗细是 `字号/24`，字号 8 以下笔粗 0.3，细线会看不见。小字直接给 `字号 12～16` 起步，或者字画完再整体缩。
6. **`找字` 的第二个参数是历史遗留**（原本想做大小写回退）。这套字库里没有重复字符，传 0 传 1 结果一样；`画文本` 内部固定传 0，你一般不用直接调它。

---

## 7. 什么时候不该用它

- 只要几个英文单词、字号固定、不需要中文 → 造型就够了，别背 5 MB。
- 要做**大量**动态文字（比如每帧刷新的计分板 20 个数）→ 引擎没问题，但你得按第 1 条只在数字变化时重画。
- 要做逐字动画（打字机）→ 可以，每帧只画前 n 个字，成本是线性的。
